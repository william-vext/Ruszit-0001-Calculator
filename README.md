# Ruszit-0001-Calculator

# what is Ruszit?
Ruszit is a class that combine Rust and Zig the 0001 means this is the first project of this class

### how Rust and Zig work in this project?
Zig in this project is the `mathematical engine` It performs all the calculations and returns the results to Rust, while Rust handles security and saves everything in the history
